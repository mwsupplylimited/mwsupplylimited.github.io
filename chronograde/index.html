Two ways to understand your watch

Hear how it is running now. The Timegrapher uses your device's microphone to estimate a mechanical watch's rate and beat error. A quiet room and a clear ticking signal matter; some watches and device combinations are harder to measure.

See how it keeps time in everyday use. Save manual readings against the app's time reference, then return later for another reading in the same session. The change in offset shows the watch's average gain or loss across that interval. Network time correction, consistent timing and longer intervals help make those comparisons useful.

An acoustic estimate is a snapshot. A manual drift trend covers the time between readings. Neither is a chronometer certification or a replacement for a watchmaker's assessment.

Getting started

  • Add a watch with the + button. Brand and model are required; everything else (reference, serial, caliber, purchase price, photo) is optional.
  • Try the Timegrapher. In a quiet room, keep the watch and device steady on a soft, stable surface. Bring the microphone close to the watch without pressing or dragging either object against the other. Start listening and let the signal settle. Use AUTO beat-rate detection or select the movement's known BPH.
  • Save a manual reading. Open the watch and tap Record Measurement. Choose the time its hands will show, tap RECORD when they reach it, then review and Save.
  • Return for a second reading. Leave time between readings — for example, return the next day. Keep the watch running without resetting it, and record into the same session. One reading shows an offset; two separated readings can show a rate.
  • Check the time reference. Tap the sync icon on the Watches tab to request network time. The recording screen indicates when it is using the device clock instead.
  • Keep resets separate. If the watch stops or you change its time, the old and new offsets do not form one continuous trend. Pro's Watch was reset — start new session action keeps those runs separate. See the session guide.
  • Personalize under Settings → Theme Shop. Two themes are free; premium themes can be unlocked with a one-time purchase.

What counts as an "accurate" measurement?

A useful manual comparison needs separated readings from one uninterrupted session, a usable time reference and consistent button timing. Network conditions and reaction time affect the result. Acoustic estimates also depend on the ticking signal, background noise, device placement and beat-rate setting. A stable-looking number alone does not establish accuracy; repeat the reading and compare it with the watch's longer-term drift. The first-readings guide walks through both methods.

What's a good rate?

Start with the manufacturer's specification for your watch and compare repeated readings under similar conditions. Position, winding state and everyday use can change what you observe. Chronograde's colors and Chronometer Score are app summaries, not a certification or diagnosis. Keep useful history to discuss with a watchmaker if a persistent change concerns you.

The sync button shows "Could not reach a time server."

Chronograde queries public time servers using UDP port 123, which some Wi-Fi networks block. Complete any Wi-Fi sign-in, try another connection, then tap the sync icon on the Watches tab. A failed refresh can retain a still-usable earlier correction; without a usable correction, the app uses the device clock and labels the reading accordingly.

Does it sync between my iPhone and iPad?

If iCloud (CloudKit) is enabled for Chronograde and you're signed in with the same Apple ID on both devices, your watches, measurements, wear log, and service history sync automatically. Settings → iCloud shows the current status.

Can I export my data?

Backup and restore are free: use the Watches tab menu to save a backup file or restore one. With Pro, that menu also offers Export to Excel, Export to CSV, and Import from CSV. A backup and a spreadsheet export serve different purposes; use the backup feature when you want an archive for restoration.
