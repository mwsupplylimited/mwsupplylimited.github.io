Offline development update · 14 October 2026

The latest development app generates Gemma 4 E2B minutes on the device after an explicit model import, and encodes MP3 locally in project and batch exports. These operations do not upload audio or transcripts or switch to a cloud service. Offline speech also supports vocabulary hints. The latest source now includes local anonymous speaker suggestions for transcribed recordings up to three minutes, using a bundled, verified model. Suggested labels require review and can be undone; mixed or overlapping passages remain unassigned. No reusable voice profiles or real-person identification are provided. The imported Gemma model can be removed without deleting projects and is excluded from device backup; bundled speaker/separation models are removed with the app; opening an external model download link is a separate network action.

The latest development app also separates voice/vocals and background on the device using a bundled verified Spleeter model, without uploading a recording or using processing credits. It previews, balances and exports real stems as AAC/M4A, MP3, WAV, FLAC and AIFF; approved redactions are applied before processing and to both saved stems. The private original is preserved. Tests cover selected recordings and simulators, not guaranteed quality: separation may remove wanted speech, leave leakage or introduce artifacts, and vocal bandwidth is limited. It cannot reliably isolate each overlapping speaker. Physical-device and broader listening checks remain open.

The latest development source asks questions across user-selected transcripts locally with Gemma and displays exact cited quotations for review. Private saved question checkpoints contain selected quotations and project references, are excluded from backup and bounded to32MiB, and can be cleared in Storage. Deleting a project discards these disposable checkpoints. Removing the model preserves saved checkpoints, so complete unchanged answers can still reopen without inference. Offline search/questions are included in Local Tools or Pro after model import. Phone/iPad saved-answer replay and original source playback pass real simulator UI checks; Phone missing-answer replay and real-request cancellation/relaunch checks also pass with no invented citation. Fresh-inference UI, interruption at every stage, natural-recording accuracy and physical performance remain release gates. current cross-meeting continuity still has a legacy explicitly approved service path. Stem exports now support verified AAC/M4A, MP3, WAV, FLAC and AIFF settings; converting a lossy recording to a lossless file does not restore lost quality.

Prepared exports in the latest development source recheck the complete original file and reviewed edits before sharing, using incremental SHA256 reads. Simulator checks verify an approved privacy AAC/SRT copy, complete audio decoding, preserved original bytes, and actual local Save to Files on iPhone and iPad with matching destination bytes. The export-ready screen also offers a direct full-screen Files picker for accessible iPad use. This does not guarantee removal of every sensitive paraphrase or compatibility with every destination; review share copies before sending them.

Simulator and real-file checks are documented; they do not establish physical-device performance. The uploaded Build 21 predates these changes and still has the legacy approved service paths described below. Full offline conversion, AI accuracy, summary length and long-recording support, and physical-device verification remain incomplete. SoundBrief is not yet released to clients.

Speech activity · offline development tool

Project tools → Find speech locates suggested speech regions using a small model included in the app. No account, model download or recording upload is needed. Selecting a region selects the corresponding retained audio; it does not automatically cut sound or infer words or speaker identities. Quiet speech, overlap and singing can be misclassified, so listen before editing.

Saved activity timings stay in private app storage, excluded from backup, and can be cleared in the tool or removed with the project. Temporary analysis audio is deleted after completion or cancellation; interrupted owned working files are recovered on the next analysis. Originals are preserved. Phone and iPad simulator checks cover real inference, replay and selection; physical performance, manually labelled boundary accuracy and long-file stress remain release checks.

Preparation disclosure, not a submitted App Store label. Reviewed against the development app and remaining legacy optional service paths on 14 October 2026. The requested release will process AI offline; final removal/replacement of legacy upload paths, shipping-binary verification and App Store questionnaire reconciliation remain pending.

Optional service data linked to your account

The current privacy manifest declares these categories for app functionality, linked to the account and not used for tracking:

  • Audio Data: approved audio processing and export jobs.
  • Other User Content: transcripts, evidence, project references and generated content.
  • User ID: authentication, account isolation and purchase binding.
  • Purchase History: verified transactions, allowances and entitlement reconciliation.
  • Search History: selected-recording questions and retained request/results.
  • Other Usage Data: processing reservations, completed usage and remaining allowances.

These declarations cover optional online paths. Local-only project storage is not an upload. Optional processing that is a core feature still requires disclosure under Apple's App Privacy guidance.

Tracking and advertising

No tracking, advertising SDK or advertising-targeting use is configured. Recordings and transcripts are not used for advertising or model training. Payment-card details are handled by Apple, not collected by SoundBrief.

Before release

The final App Store questionnaire must also review support email handling, Apple/Shazam service practices, host request logs, backups and every enabled processor. This preparation page does not claim those release checks are complete. The Privacy Policy explains current controls, retention limits and support contact information.
