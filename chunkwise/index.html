Chunkwise

Live server maps, who’s online, and an offline field guide for iPhone & iPad. Version 1.0

What Chunkwise does: it shows a live player map for servers running Dynmap, BlueMap or squaremap; tells you who’s online on any Java or Bedrock server with no setup; and gives you an offline, hand-written guide to crafting, mobs, enchantments, potions, biomes and ore levels, plus calculators a wiki can’t do. It is honest about what is and isn’t possible — see “About the live map” below.

Getting started

Add a server

Open the Servers tab and tap +. Enter a name, the server address (for example play.example.com or play.example.com:25565), and choose Java or Bedrock. Chunkwise pings the server and shows its MOTD, player count, version and ping. The free version keeps up to three servers; Chunkwise Pro is unlimited.

See who’s online

Tap a server to open it. The player count is always accurate. Individual player names are shown only when the server publishes them — that needs the server to enable the Query protocol (enable-query=true) or to run a live web map. Chunkwise never invents or guesses names, and never shows the fake “advertisement” names some servers put in their server-list response.

About the live map

Chunkwise can show a real, live map with player positions — but only for servers that publish one. Add the map’s web address (the URL you’d open in a browser) to a server, or paste it on the Map tab.

  • Works: servers running Dynmap, BlueMap or squaremap with player tracking enabled. Positions update in real time.
  • Works (server owners): live positions from a server you own, via RCON Admin Mode (Chunkwise Pro).
  • Does not exist: live positions for Realms or for single-player worlds. No such data is available to any third-party app, and Chunkwise does not pretend otherwise.

Most large public networks don’t run a public web map (live coordinates are a griefing risk), so the live map works best on smaller SMP and community servers. When a map hides some players (vanished, spectator, or hidden by the admin), Chunkwise shows “showing N of M online” so you always know.

Chunkwise Pro

Chunkwise Pro removes ads and unlocks unlimited saved servers and waypoints, friend-join alerts, base-proximity alerts, player & map history, RCON Admin Mode, iCloud sync and faster refresh. It’s available as a monthly or yearly subscription, with a 7-day free trial on the yearly plan. There is no lifetime or weekly plan.

Manage or cancel

Subscriptions are billed by Apple through your Apple Account and renew automatically until cancelled. Manage or cancel any time in Settings → [your name] → Subscriptions on your device, or from Settings → Membership inside Chunkwise. Cancelling keeps Pro until the end of the paid period.

Restore purchases

New device, or reinstalled the app? Open Settings → Restore purchases (also on the Membership screen). Your subscription is tied to your Apple Account.

Ads & privacy

The free version shows a banner and an optional rewarded video, served by Unity LevelPlay (ironSource). Ads never cover the live map, and never sit next to a control. Chunkwise has no account and no servers of its own; your saved servers and waypoints stay on your device (and, with Pro, in your own private iCloud). RCON passwords are stored only in your device Keychain and are never synced or sent anywhere but the server you configured. Full details are in the Privacy Policy.

Troubleshooting

“Offline or unreachable”

Check the address and port, that the server is online, and that it isn’t blocking status pings. Bedrock servers use a different default port (19132) — make sure the edition is set correctly.

The map says it can’t load

Paste the map’s web address (the page you open in a browser), not the game server IP. The map must be a Dynmap, BlueMap or squaremap page that’s reachable from the internet.

No player names on a server

That server doesn’t publish its player list. Ask the admin to set enable-query=true, or to run a web map. The player count is still accurate.
