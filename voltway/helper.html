Voltway Charge Helper

An optional download that lets Voltway control charging on your Mac.

You do not need this to use Voltway. The power-flow diagram, the battery forensics and the history all work without it. The helper only adds charge control.

Why is it a separate download?

Limiting charge means writing to your Mac's System Management Controller — the chip that actually runs the charger. That requires administrator privileges, and Mac App Store apps are not permitted to request them (App Store Review Guideline 2.4.5(v)).

So rather than ask for privileges it is not allowed to have, Voltway keeps that work in a small, separate program that you install yourself and can remove at any time. The App Store app never escalates and never installs anything.

What it does

  • Holds your battery at a limit you choose, including limits below 80%
  • Separate upper and lower thresholds, so the pack is not constantly topped up
  • Runs your Mac from the adapter without charging, or from the battery while plugged in

How it keeps your Mac safe

This program can stop a Mac charging, so it is built to fail in the safe direction:

  • It writes the safe state first every time it starts, before reading any of your settings. A crash and restart can never leave you unable to charge.
  • If Voltway stops talking to it for more than a few seconds, it releases the limit by itself.
  • If the battery falls below 20%, or gets too hot, it opens the gate regardless of your settings.
  • It restores normal charging on quit, on shutdown, and even if it crashes.
  • If it cannot reach Voltway at all, it leaves charging on rather than holding a limit nobody can release.

Requirements

  • A Mac notebook with Apple silicon, running macOS 14 or later
  • An administrator password at install time (macOS asks, not Voltway)

Some Macs do not expose a charge-control interface at all. Voltway detects this and tells you plainly rather than pretending the setting worked.

Install

Download Voltway Charge Helper 1.0 · 156 KB · macOS 14 or later, Apple silicon

Open the downloaded .pkg and follow the installer. macOS will ask for your administrator password — that prompt comes from the system installer, not from Voltway, and it is what allows the helper to talk to the charger.

Signed with a Developer ID certificate and notarized by Apple, so Gatekeeper will open it without warnings. SHA-256: b0af6806fd9c2f5a622c89d4a9c015beaa2e9abff41f049350791152ad573c28

Remove it

Run this in Terminal:

sudo voltway-helper-uninstall

It restores normal charging first, verifies by reading the setting back, and only then stops and removes the helper. If it cannot verify that charging was restored it refuses to report success, so you are never left with a Mac that will not charge.
